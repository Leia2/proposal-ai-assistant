# Proposal AI Assistant

Proposal AI Assistant is an AI-powered Google Workspace assistant that transforms Google Meet conversations into structured knowledge using Google ADK, Gemini and Google Cloud.

## Vision

The project aims to build an intelligent assistant capable of:

- Understanding Google Meet summaries
- Structuring meeting knowledge
- Answering questions through Google Chat
- Building a knowledge base for future proposal generation

> The first MVP focuses on meeting knowledge management. Budget and proposal generation will be implemented in future versions.

## Tech Stack

- Python
- FastAPI
- Google ADK
- Gemini
- Vertex AI
- Google Chat API
- Firestore
- Cloud Run
